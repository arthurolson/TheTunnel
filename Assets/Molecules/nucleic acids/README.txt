Molecules in the category "nucleic acids" (a heading in the TS Menu's Molecules list).

To add a molecule: make a folder here named as it should appear in the list (such as "EGFR"), put its model in it
(GLB, glTF, OBJ with its MTL, or FBX, in ångström, as exported from Mol* or ChimeraX), then run
Tunnel > Molecules > Update Molecule Library (it also runs by itself when a model arrives). The library makes the
molecule's networked toy in that folder, at the same ångström-to-meter scale as every other molecule.
Keep original downloads (zip, cif) in a Source~ folder inside the molecule's folder: Unity ignores it.
